# Make the AI Judge Laugh: Cat Reviews Its Human

A single-line, one-star review written by a house cat about its human owner, for the make.fun micro bounty ["Make the AI Judge Laugh: Cat Reviews Its Human"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

The entry is a deadpan one-star review in the shape of a real product review, but the complaint is unmistakably feline: the human refills the food bowl on time, then commits the unforgivable crime of sitting on the cat's warm laptop — and the cat's revenge (two knocked-over coffees) earns no apology. The sting lands in the last few words, which reveal more about the cat's sense of justice than about the owner.

`main.ts` is a deterministic Node program (stdlib only) that writes the review line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` if set, else `/output`), with a guard that throws unless the line is 1–200 characters and a single line.
